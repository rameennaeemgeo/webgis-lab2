# Professional Academic Profile & Interactive Dashboard

**WebGIS Development Course - Lab 2**
Lecturer: Jaffar Waqas | Student: Rameen Naeem

A responsive academic profile dashboard built with HTML, CSS and JavaScript, using a light blue and white gradient theme.

## Features
- "Lab 2" badge in the header
- Three-section layout: Quick Connect (left), Academic Profile (center), About the Institute (right)
- Interactive popup modals for Email, Phone Number and More Info, written with `showPopup()` and `closePopup()`
- Popups close with the close button, a click outside, or the Esc key
- Fully responsive: stacks into one column on mobile

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | Theme, layout and responsive design |
| `script.js` | Popup logic |

## Run locally
Open the folder in VS Code, install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**.
